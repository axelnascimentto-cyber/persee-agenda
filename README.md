# Persée AI • Agenda & Portail Personnel

Application Web Mobile & PWA autonome connectée à Persée (Meta Portal TV).
- **Interface Visuelle :** Calendrier, To-Do list avec priorités, Notes & Pense-bêtes, reconnaissance vocale.
- **Architecture Hybride :** Accès local direct 0 ms + synchronisation Cloud sécurisée.
- **100% Mobile First :** Conçu pour fonctionner sur n'importe quel smartphone avec cache offline persistent.
